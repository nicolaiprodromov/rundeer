    loops, bundles & previews
    
            
          
    
          
    
            
    What is a bundle?
    
            
    A bundle is just a list of values (image paths, video paths, strings, numbers) traveling on a single wire. You get one whenever:
    
            
      
              
    • A command node is set to iterations > 1 (e.g. an Image node with iterations = 5 emits 5 image paths).
      • 
              
    • A Loop · Output node collects every iteration into one wire.
      • 
            
    
            
    Bundle output sockets show a square inner ring and the wire leaving them is dashed.
    

            
    How loops work
    
            
      
              
    1. Add a Loop · Decompose node and feed it a bundle (e.g. the output of an Image node with iterations > 1, or a chain of File nodes joined into a bundle).
      2. 
              
    2. Connect Item from Decompose to whatever should run per-item (e.g. an Edit or Compress node).
      3. 
              
    3. Add a Loop · Output node with the same loop_id as the Decompose. Connect the per-item result into its Item input.
      4. 
              
    4. The shaded blue area between the pair shows what runs once per item.
      5. 
              
    5. The Output node now exposes a single bundle wire holding every iteration's result.
      6. 
            
    

            
    Previewing a bundle
    
            
    Just connect a bundle into an Image Preview or Video Preview node. The preview automatically switches into grid / slider mode (toggle inside the preview) so you can see every item.
    

            
    Live preview
    
            
    Whenever you change a text/number/loop/connection, previews update on the spot using the last results of any expensive command nodes — you only need to re-run the graph when you actually want fresh API output.
    

            
    Props as sockets
    
            
    Every prop in the right-hand panel also appears as an input socket on the node. Connect a wire to override it from upstream — the panel control turns grey and shows ← from socket.
    

            
    Handy shortcuts
    
            
      
              
    • T toggle palette · P toggle properties · R toggle runs panel
      • 
              
    • G grab/move · S scale · Ctrl+X cut · Shift+A add node
      • 
              
    • Alt+right-mouse drag between two nodes — auto-connects the best matching sockets
